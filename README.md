# snowball-mcp

A self-improving code-maintenance brain, delivered as an MCP server, that attaches to any
repository and grows its own adapters, judges, memories and agents from measured need.

This repository currently holds the **specification** the founder agent builds from. No brain
code exists yet; Stage 0 creates it.

- Start here: [`spec/INDEX.md`](spec/INDEX.md)
- Founder agent seed: [`spec/tohum/00-cekirdek.md`](spec/tohum/00-cekirdek.md), then
  [`spec/tohum/00a-sinirlar-operator-ilk-gorev.md`](spec/tohum/00a-sinirlar-operator-ilk-gorev.md)
- One-time operator setup: [`spec/tohum/25-kurulum-gunu.md`](spec/tohum/25-kurulum-gunu.md)

The specification is written in Turkish, the operator's language. Everything the system itself
produces (findings, organ pages, ledgers, status reports) is in English.
